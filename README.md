# Welcome to injectx

## Prerequisites for Linux

Following packages are required(this may not be the exhaustive list):
* cmake
* ninja-build
* curl
* zip
* unzip
* tar
* pkg-config
* pre-commit
* clang-format


For Ubuntu you can use:

    sudo apt install cmake \
                     ninja-build \
                     curl \
                     zip \
                     unzip \
                     tar \
                     pkg-config \
                     pre-commit \
                     clang-format
